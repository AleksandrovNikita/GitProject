# Салат Греческий

# Ингредиенты:

# 

# · Помидоры — 3-4 шт.

# · Огурцы — 1-2 шт.

# · Болгарский перец — 1 шт.

# · Красный лук — 1/2 шт.

# · Маслины — 100-150 г

# · Сыр фета — 150-200 г

# · Орегано — 1 ч. ложка

# · Оливковое масло — 4-5 ст. ложек

# · Лимонный сок — 1 ст. ложка

# · Соль, перец — по вкусу

# 

# Приготовление:

# 

# 1\. Помидоры нарезать крупными кусками, огурцы — полукружиями, перец — кольцами.

# 2\. Лук нарезать тонкими полукольцами.

# 3\. Смешать овощи, добавить маслины.

# 4\. Сверху положить цельный кусок феты.

# 5\. Полить оливковым маслом и лимонным соком, посолить, поперчить.

# 6\. Посыпать орегано.
